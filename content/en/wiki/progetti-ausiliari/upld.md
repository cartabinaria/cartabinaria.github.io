`upld` is a CartaBinaria project intended to make file contribution easier. Its
goal is to allow uploading resources without needing to know the Git and GitHub
procedures for contributing to a project.

The [project README](https://github.com/cartabinaria/upld) recommends resuming
development only after completing
[`polleg`](https://github.com/cartabinaria/polleg).

The Go package documentation is available on
[pkg.go.dev](https://pkg.go.dev/github.com/cartabinaria/upld).
